# ADR (설계 결정 기록)

파일 이름은 `NNNN-짧은-제목.md`로 쓰고 번호는 이어서 붙인다. 이미 정한 결정을 바꿀 때는 원래 문서를 고치지 않는다. 새 ADR을 쓰고, 원래 문서의 상태를 `대체됨 (→ NNNN)`으로 바꾼다.

## 목록

| 번호 | 제목 | 상태 |
| --- | --- | --- |
| [0001](0001-writing-hint-ja-meaning.md) | 쓰기 문제에 일본어 단어 뜻 힌트 추가 | 채택 |

## 템플릿

```markdown
# NNNN. 제목

- 날짜: YYYY-MM-DD
- 상태: 제안 | 채택 | 대체됨 (→ NNNN)

## 배경
무엇이 문제였고 왜 결정이 필요했는지.

## 결정
무엇을 하기로 했는지.

## 결과
좋아진 점, 감수한 점, 나중에 다시 볼 것.
```
