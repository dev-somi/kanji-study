# 0001. 쓰기 문제에 일본어 단어 뜻 힌트 추가

- 날짜: 2026-11-25
- 상태: 채택
- 커밋: a429028

## 배경
쓰기(w) 문제 화면에는 힌트가 두 가지 있었다. 하나는 `힌트 (획수)`로 획수와 학년을 보여 주고, 다른 하나는 `힌트 (단어)`로 한국어 한자어의 한글만 보여 준다. 그런데 한국어에서 잘 쓰지 않는 글자는 단어 힌트가 비어 있었다. 또 일본어에서만 자주 쓰이는 뜻은 떠올릴 실마리가 없었다.

## 결정
- `힌트 (일본어)` 버튼을 추가한다. 누르면 일본어 예시 단어(`words.json`의 `ja`)의 **한국어 뜻만** 보여 준다. 정답 화면의 "예시 단어 › 일본어"에 나오는 뜻과 같다.
- 한자와 가나 읽기는 보여 주지 않는다. 쓰기 문제의 정답은 한자 모양이므로 한자는 정답 그 자체이고, 가나 읽기는 2단계(읽기)에서 묻는 내용이기 때문이다.
- 기존 `힌트 (단어)`는 `힌트 (한국어)`로 이름을 바꾼다. 두 힌트를 함께 열면 줄 앞의 `한` / `일` 표시로 구분한다.
- `Examples`의 prop은 `hangulOnly: boolean` 대신 `hint: 'ko' | 'ja'`를 쓴다.

## 결과
- 데이터는 이미 2136자 전부에 들어 있어서 빌드 스크립트를 바꿀 필요가 없었다.
- 일본어 뜻이 한국어 단어와 같은 경우가 많다(예: 毎日 → 매일). 그래서 두 힌트를 다 열면 같은 말이 겹쳐 보일 수 있다. 일부러 그대로 두었다.
- 버튼이 세 개가 되어 좁은 화면에서는 줄바꿈된다(`.hint-btns { flex-wrap: wrap }`).
