# '10개 더'를 여러 번 눌러야 카드가 나옴

- 날짜: 2026-11-20
- 관련 커밋: e9f3e6c

## 증상
새 한자를 다 끝낸 뒤 `새 한자 10개 더`를 눌러도 카드가 나오지 않았다. 여러 번 눌러야 겨우 나왔다.

## 원인
'10개 더'로 늘린 추가분(`extraNew`)은 기기마다 따로 저장된다. 반면 오늘 배운 새 카드 수는 동기화된 로그로 센다. 그래서 다른 기기에서 많이 배운 날에는 이미 `하루 한도 + 추가분`을 넘긴 상태였다. 이때 +10을 해도 여전히 한도 아래였다.

## 해결
[src/lib/db.ts](../../src/lib/db.ts)의 `addExtraNew`를 고쳤다. 이제 오늘 배운 수(모든 기기 합계)와 지금 한도 중 큰 값을 기준으로 10개를 더 연다.

## 재발 방지 / 참고
기기별 로컬 상태(meta)와 동기화되는 상태(cards, logs)를 섞어서 계산할 때는, 다른 기기에서 진행한 경우를 반드시 생각한다.
