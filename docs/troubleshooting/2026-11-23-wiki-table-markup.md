# 腕의 훈독에 위키 표 마크업이 섞임

- 날짜: 2026-11-23
- 관련 커밋: 732aa10

## 증상
腕(상용한자 목록의 마지막 글자)의 훈독에 위키 표 마크업과 다음 절의 텍스트가 섞여 나왔다.

## 원인
ja.wikipedia「常用漢字一覧」 wikitext를 행 단위로 나눌 때 문제가 있었다. 표의 마지막 행에는 표를 닫는 줄(`|}`)과 그 뒤의 다음 절 내용까지 같은 셀에 딸려 왔다.

## 해결
[scripts/build-data.ts](../../scripts/build-data.ts)의 `parseWiki`에서 읽기 셀은 첫 줄만 쓰도록 했다. 그다음 `npm run build-data`로 `public/data/kanji.json`을 다시 만들었다.

## 재발 방지 / 참고
위키 원본을 파싱할 때는 표의 첫 행과 마지막 행이 경계 문제를 일으키기 쉽다. 데이터를 다시 빌드하면 첫 글자와 마지막 글자를 직접 눈으로 확인한다.
